# AiFrame
Фоторамка с нейросетями

Этот репозиторий обновление версии описанной в (https://alexgyver.ru/aiframe/)
Данный форк создан при помощи Claude Code. 

Изменения коснулись Хардваре и используемого ЭйАй айпиая.
 - Контроллер - ESP32_CYD (Cheap Yellow Dysplay) [ESP32 Touchscreen 2.8inch TFT LCD Display ILI9341 Resistive Touch Module 240 * 320](https://a.co/d/0iIP7qFS)
 - AI Генератор изображений - [pollinations.ai](https://enter.pollinations.ai/sign-in). Полинейшин ЭйАй позволяет использовать различные модели и в случае самой дешевой, бесплатный бюджет позволяет запрашивать около 10 генераций в час.

Изменения в ВЕБ интерфейсе - незначительные, добавлено последнее сгенеренное изображение. Последнюю картинку можно скачать перейдя на страничку настроек.
